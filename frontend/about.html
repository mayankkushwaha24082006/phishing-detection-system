About this project

What is phishing?

Phishing tricks people into entering private data on a fake website that looks real.

How phishing attacks work

An attacker sends a message with a link to a look-alike site. The victim enters their login or card details, and the attacker collects them. Tricks include look-alike domains, hidden redirects, the @ symbol, URL shorteners, and IP addresses instead of names.

Why detection matters

Phishing is one of the most common causes of account theft and data breaches. Blocking links before a click prevents damage that is hard to undo.

How Machine Learning helps

Blocklists only know sites that were already reported. A model learns patterns from many examples, so it can flag new sites that nobody has reported yet.

Algorithms implemented

Random Forest

Primary model. Many decision trees vote together.

Decision Tree

Comparison model. Simple, readable rules.

Logistic Regression

Comparison model. A fast linear baseline.

Limitations

The model reads the domain name only, because the training data's paths and HTTPS were a shortcut. The final risk score blends the model with rule checks. This is a decision-support tool and cannot guarantee that a website is safe.
